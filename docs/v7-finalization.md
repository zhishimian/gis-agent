5. 逐项审查 Git 差异和分支。提交有效代码、Skills、测试及必要文档；排除密钥、原题、数据、Session 和实验产物。合并 main 后再次免费验证。保留历史实验原件。

### 冻结边界与剩余问题

V7 可冻结为开发基线。冻结不代表完整竞赛能力或发布环境已经验收。

- 达到模型真实输出上限仍可能 length。当前明确停止并保留原件。本轮采用用户指定的增大上限方案，未实现自动重生成。8192 的历史终止点尚未通过真实 API 复测。
- 输出预留增加，输入预算同步减少。长历史可能更早需要压缩。更长生成也可能增加延迟和费用。
- 原生脚本调用仍缺少任务级进度、超时及安全取消。缓存知识已提供，尚无自动工作流依赖管理。
- 生产环境仍依赖本机 QGIS，部分 GIS 库来自用户级 site-packages。跨机器打包与全量 GDAL 驱动兼容未验收。
- Skills 的专业规则和小反例已离线验证。模型是否及时采用、是否提高未知任务正确率，仍需后续获准的真实对照。
