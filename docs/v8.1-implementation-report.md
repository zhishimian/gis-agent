## 2. 真实接口与执行事实

Agent 先按需要调用 execution_history，再提交 `local_replay(plan)`。plan 使用真实 source_execution；输入绑定 accepted 或 step/output，changes 修改参数或代码，outputs 分配新相对文件名，targets 决定本次依赖闭包。

`replay(plan, history, execute, output_dir, *, resolve_tool, environment)` 组合当前工具。程序不请求模型决定每个已确定阶段。

根调用只产生一条正常 Session 工具结果。子阶段使用 `r_<repair_id>_sNN` 回执，不插入虚构的 assistant/tool 消息。execution_history 可以按子执行 ID 查询实际参数、返回、快照及日志。

成果目录为 `output/repairs/<repair_id>/`。plan.json 固定说明，inputs/ 保存当前输入副本，attempts/<step>/ 保存冻结代码、辅助文件和 job.json。输出使用本修订内的新文件。关键子记录继续保存在本 Session 的 executions/。

同 repair_id、相同计划回读已有终态；不同计划拒绝。新 repair_id 可以通过 parent_repair 继承家族成功结果。原始工作脚本及旧成果保留。

### Python 轻契约

普通脚本继续自由执行。受控脚本读取 sys.argv[1] 指定的 JSON，其中含 inputs、parameters、outputs；可以使用任何现有可用 Python/GIS 方法。

changes 明确声明 job_contract=true、side_effects=outputs_only。patches 复用原 edit_file 的唯一匹配和 SHA 校验。candidate_script 需要明确 SHA。主脚本和辅助文件冻结到新 attempt，cwd 与 __file__ 都在该新目录。

deterministic=true 允许在明确依赖声明下复用。程序无法普遍证明 Python 没有隐藏依赖。没有保存的内存不能恢复。

### QGIS 边界

首版受控调用限 native:reprojectlayer、buffer、intersection、clip、dissolve、fixgeometries。它们覆盖本次真实参数修复及局部叠加验收。

这个范围避免把数据库、工程表达式或插件副作用假装成完整可控的文件计算。其他算法仍可使用原动态工具或受控 Python。算法定义改变时拒绝沿用旧配置；首次提升采用的当前默认参数明确进入有效调用。

## 3. 身份、依赖和缓存

普通 V8.0 历史只有观察线索。它没有自动获得缓存资格。首次采用未充分记录的历史输入，要求 adopt_current 和理由，并保留 historical_identity=unverified。

受控输出重新核验内容后可以作为新输入，标 verified_controlled。新的本地输入先复制并核对前后内容。GPKG 使用全文件身份，任何层变化都保守失效。TIFF 文件内容包含 CRS、NoData、网格和像元变化；发现常见外部 sidecar 时拒绝封存。WAL/SHM/journal、网络共享、VRT、数据库和未保存图层不进入此缓存。

复用签名包含输入内容与选择器、有效参数、冻结主代码、声明辅助文件、输出端口和格式、执行实现及环境身份。mtime 和 size 不单独作为内容依据。缓存仅查当前 Session 的修复祖先。

输出缺失、内容变化、代码或辅助模块变化、环境身份变化、关键记录损坏都会阻止复用。多输出作为一个阶段核对。声明子图负责下游影响范围；普通 Python 的未知消费者不自动推断。

环境探针记录实际 Python、QGIS/GDAL/PROJ/GEOS 及相关 Python 包版本和模块文件。后续调用重新核对已观察模块、启动器及项目执行助手的内容。它仍限定在受管理本机环境，未穷举所有系统 DLL、PROJ 网格和外部环境变量。这项限制需要在发布与环境升级时单独验收。

## 4. 故障和窄恢复

V8.0 普通执行回执继续是辅助观察。写失败只告警，原 Session 与异常保护不变。

V8.1 意图、计划、输入版本、完成回执和根结果属于关键记录。写入失败不能发布可信成功。关键 JSON 使用原子替换和内容校验；这用于检测损坏，不提供对恶意本机进程的身份认证。

跨进程文件锁防止同修订并发执行。进程终止后操作系统释放锁。文件存在本身不构成完成证据。

| 中断现场 | 实际行为 |
| --- | --- |
| 计划保存，未启动计算 | 在原根调用基准一致时重新准备未执行部分 |
| 意图保存，执行结果未知 | unknown，拒绝自动重试 |
| 文件已生成，缺少完成回执 | unknown，保留部分文件 |
| 前缀完成，后段正常失败退出 | partial/failed；新修订可继承可信前缀 |
| 子阶段完成，根结果未写 | 校验子阶段，重建终态或执行明确未启动阶段 |
| 根完成，Session 尚未保存 | 只补同一条工具结果，不重新计算 |
| Session 领先于 Checkpoint | 校验精确尾部和原检查点，正式 update_state(as_node="tools") 后继续 |

自动恢复只覆盖单独提交的 local_replay。需要同 Session/thread、原调用、计划、前缀、检查点 ID/状态与文件版本一致。额外消息、变动前缀和未知副作用会拒绝恢复。

新运行使用 version=810。旧 790 仍按原严格哈希路径续跑；不会对旧哈希冲突普遍放行。没有修改 SQLite 内部表，没有恢复旧模型思考状态。

### A 的真实行为

模型识别50米与500米不一致，采用现有投影成果，直接搜索并调用标准缓冲和相交工具。没有重新启动投影，也没有改写任何输入或旧成果。

第一次相交调用发生在该工具尚未进入当前可调用 Schema 时，被程序拒绝；搜索后再调用成功。随后自编核查脚本将单个 Shapely 几何的 geom_type 字符串当作 Series 使用，出现 AttributeError；模型用 edit_file 改正后运行成功。这两次错误均保留。

组织者独立检查确认：新缓冲 EPSG:32650、1个有效要素、id=7，面积785082.7892387134平方米；与 Shapely 500米、32段/象限的独立几何对称差为0。新叠加面积355459.6397798723平方米，与独立几何相交对称差为0。旧8个数据文件哈希全部不变。

输入本来已在EPSG:32650，原投影是恒等投影。这个模型样本证明保留适用上游，不能据此证明复杂坐标变换的修复能力。独立离线对照另外验证了实际重投影工具的调用次数和完整重算一致性。

离线三阶段样本同样使用同 CRS 投影调用。跨 CRS 的局部修复组合仍需后续补充样本，本轮结束后没有追加测试。

### B 的真实行为

模型直接读取工作脚本和中间 JSON，发现 items 与实际 values 键不一致，用带 expected_sha256 的 edit_file 修改一行，再运行普通 run_python_script。

独立读取结果为 sum=12，prefix_count 仍为1，中间 JSON 与计数文件哈希未变。工作脚本按普通编辑语义发生改变，旧执行快照继续保留。这次没有产生受控修订，不能将其描述为实际使用了冻结代码或修复家族缓存。

B 的首次 KeyError 属于收费前构造的真实故障样本。收费修复期间没有新的工具失败。

### 真实证据能支持什么

两项都在当前会话中完成了修复，并保留适用成果；模型自主选择了原工具和编辑路径。它们没有读取 execution_history，也没有选择 local_replay。因此，本轮证明普通 Code Agent 路径在新增工具后仍可使用；**新历史工具与受控重放的真实自然采用、净 Token 收益仍未得到证明**。

受控 local_replay 的多阶段运行、缓存和恢复已有真实离线计算证据，模型接口闭环有固定回复及 MockTransport 证据。这几类证据需要分别判断。

A 的核查仍较长，最终说明也偏长。单次 local_replay 的 JSON 契约是否会使模型更犹豫，目前只有风险判断。本轮结束后没有通过强制工具或追加收费测试追求采用率。

## 8. 能力边界与下一步

V8.1 已实现真实局部修订、自由 Python 的受控补丁与后段执行、修复家族内复用，以及单根工具调用的受限中断恢复。

它不能恢复已丢失的 Python 内存，不能自动发现所有脚本依赖，不能恢复活动数据库或未知副作用，也不自动证明 GIS 专业正确性。原环境升级、未管理 sidecar、不可确认的外部输入或不确定完成记录需要人工核对，或明确选择自由执行与重新计算。

局部子图仅覆盖 Agent 本次声明的阶段。未声明消费者不会被程序自动找全。代码、参数和算法仍由原模型决定；程序处理已确定的执行与文件身份。

修复工具的契约明显比直接编辑一行代码更重。小任务应继续自由选择直接修改。历史查询也可能增加一次模型往返。是否采用取决于定位成本、中间成果价值和失败范围。

下一轮优先观察三点：真实模型是否自然选择合适路径；环境检查对小任务的净开销；局部计划是否过长。不要通过增加更多强制流程来掩盖这些问题。
