# Thematic cartography

Design every map around the user's geographic question. Reuse verified analytical layers, fields, units and CRS; inspect geometry types, NoData masks and extent before styling. Never fabricate unverified layers; disclose incomplete coverage outside the figure.

## Non-negotiable aesthetic & engineering rules
1. **Zero unrequested sub-panels, zero subtitles & concise legends**: Do NOT add unrequested statistical sidebars, long `add_leader_callouts` lines, or redundant macro locator insets on iconic continental/national extents (e.g., CONUS, China, Global—reserve locator insets for local/provincial study areas). NEVER add a subtitle line (`subtitle_detected_warning`), `Sources:` footers, or dual count + `%` legend columns: keep legends strictly `Variable (unit)` with category names and at most one numeric value `(n)`, using centered bold `"Legend"` + light border (`add_clean_legend(..., frameon=True, title_align="center")`) in dedicated sidebar panels. Match prompt language via bundled open-source print typography (`configure_plotting(font_style="serif")` for `Source Serif 4 + LXGW WenKai Lite`, or `"kaiti"`).
2. **Seamless zero-anchored continuous colorbars & layer z-order**: Non-negative continuous rasters/fields MUST pair `get_scientific_cmap("sequential", "nordic_snow", zero_anchored=True)` + `build_perceptual_norm(values)` + seamless `add_continuous_colorbar(..., zero_label=None)` so `0` blends smoothly on the left end while `NoData` stays hatched `#d9d9d9`. Enforce strict `zorder`: context land/ocean (`0-1`) -> thematic fills (`2`) -> lakes/hydro (`3`) -> minor internal borders (`4`) -> points/roads (`5-6`, white edge halos) -> **national / primary study-area boundary (`zorder=8`, NEVER occluded by dots)** -> chrome (`10+`).
3. **Clean map face, integer graticules & lower-zone scalebar**: NEVER stamp the study area's own name across the middle of the study polygon when it is already in the figure title—label only quiet surrounding neighbors/oceans in muted italic text, and place `add_leader_callouts` only when named peaks/sites are explicitly requested. Always place scalebars in the **lower zone** (`lower left`/`lower right`/`lower center`), keep `compass_star` inside spines (`frame_overflow_warning == False`), and call `add_graticule_frame(ax, crs=...)` without arbitrary metric steps so projected maps automatically receive crisp integer-degree DMS ticks.
4. **Standard study-area locator discipline**: Always paint surrounding states/countries on the MAIN map (`zorder=1`, `#efeeea` fill + `#c4c0b8` borders—never float the study zone on blank white). Crop the macro locator tightly around the host country + neighbors inside `add_locator_inset(..., shape="circle" or compact rect)` with a clean dashed focus box (no cross-axes connector lines), and anchor the framed sidebar legend lower and horizontally centered below it.
5. **4-tier even fonts & fast vector budgets**: Keep standalone maps `~8.5-9.0 in` wide with `<= 4` even-integer font sizes (`10 / 12 / 14 / 16 pt` via `apply_publication_theme(..., fig_width=...)`). Never plot via `for row in gdf.itertuples()`; simplify `> 5,000`-feature layers and set `rasterized=True` on continuous rasters/dense backdrops so each render finishes `<= 15 s`, preserving `>= 2` `read_image` QA rounds.
